## Scaling Techniques

### 1. StandardScaler

Standardizes data using:

z = (x - μ) / σ

Features:
- Mean becomes 0
- Standard deviation becomes 1

---

### 2. MinMaxScaler

Normalizes data using:

x' = (x - xmin) / (xmax - xmin)

Features:
- Values scaled between 0 and 1
